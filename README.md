# SQL Data Analysis — Task 04

This project performs SQL-based analysis on a movie dataset using MySQL.

## Objectives

* Create and import database tables
* Insert movie dataset
* Extract data using SELECT
* Filter data using WHERE
* Sort data using ORDER BY
* Group data using GROUP BY
* Use aggregate functions
* Perform JOIN operations
* Produce useful analytical results

## Database Tables

### Movies

Contains movie title, release year, rating, and genre ID.

### Genres

Contains genre IDs and genre names.

## SQL Operations Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* JOIN
* COUNT()
* AVG()
* MAX()

## Project Files

* `movies.sql` — Creates the database, tables, and inserts the dataset.
* `analysis_queries.sql` — Contains SQL queries for data analysis.

## Tools Used

* MySQL
* phpMyAdmin
* SQL

## Analysis

The project analyzes movie ratings, filters highly rated movies, sorts movies by rating, counts movies by genre, calculates average ratings, finds the highest rating, and combines movie and genre information using JOIN queries.
